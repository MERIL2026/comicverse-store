 🎨 ComicVerse Store

ComicVerse Store is a modern comic-inspired e-commerce website built with cinematic UI design, smooth animations, and responsive layouts.

The project focuses on creating an immersive shopping experience using modern frontend technologies and futuristic visual effects.

## 🚀 Features
- Modern cinematic UI
- Responsive design
- GSAP animations
- Dark futuristic theme
- Interactive product sections
- Smooth transitions & effects

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- GSAP
